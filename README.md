# 🎨 Moodist - Premium Apparel Platform

Welcome to the **Moodist** frontend repository. This project is a modern, high-performance e-commerce platform for custom apparel, featuring interactive 3D product previews and a sleek, animated user interface.

## 📚 Documentation

For a detailed breakdown of the architecture, tech stack, folder structure, and development guidelines, please refer to the:

👉 **[DOCUMENTATION.md](./DOCUMENTATION.md)** (Detailed Technical Guide)

## 🚀 Quick Start

1.  **Install dependencies**:
    ```bash
    npm install
    ```

2.  **Run the development server**:
    ```bash
    npm run dev
    ```

3.  **Build for production**:
    ```bash
    npm run build
    ```

## 🛠️ Key Technologies

- **Next.js 15/16** (App Router)
- **Tailwind CSS 4**
- **React Three Fiber** (3D Previews)
- **Framer Motion** (Animations)
- **Shadcn/UI** (Components)
